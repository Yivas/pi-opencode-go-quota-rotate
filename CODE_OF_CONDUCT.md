# Code of Conduct

Discussion should address the proposal or behavior, not the person. Disagreement and criticism are welcome when supported by examples. Harassment, discriminatory attacks, threats, spam and publishing private information are not accepted.

This applies to issues, pull requests and other project spaces, including statements made as a project representative. The maintainer may edit or remove harmful content, lock discussions or restrict participation; repeated or severe abuse can lead to a ban.

Public moderation questions can be raised in an issue without naming victims or exposing private material. Abuse reports needing confidentiality use [the repository's private reporting channel](https://github.com/Yivas/pi-opencode-go-quota-rotate/security/advisories/new), identifying the report as “Conduct report”; unrelated reports may be redirected privately. No response deadline is promised.
